# Public Site Contract

## Current implemented surface

- homepage
- about page
- contact page
- book page
- events page
- blog index and blog slug route
- medical and wellness service pages
- membership page
- privacy, terms, accessibility, and HIPAA pages
- team and partners pages

## Current behavior limits

- this repo does not implement custom appointment booking flows; booking routes users to Zocdoc
- this repo does not currently expose authenticated patient or provider workflows
- this repo does not currently implement a CMS-backed blog editor or event management backend

## Messaging rule

If the code only presents informational content, the copy should say that plainly.
