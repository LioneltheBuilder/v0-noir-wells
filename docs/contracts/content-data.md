# Content Data Contract

## Current sources

- `lib/config.ts`: contact data, tagline, and booking URL
- `app/` route files: page copy and metadata
- `components/`: homepage section copy and structure
- `public/images/`: branded imagery

## Rules

- centralize repeated business/contact strings in `lib/config.ts`
- avoid copying the same claim into multiple places unless necessary
- when route messaging changes materially, update docs and relevant metadata
